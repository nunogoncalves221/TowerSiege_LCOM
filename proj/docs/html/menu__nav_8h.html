Detailed Description

Reusable keyboard navigation and item rendering for all menus.

Provides a generic UP/DOWN/Enter handler and a single-item draw function used by every menu screen to keep navigation behaviour consistent.

Draws a single menu option with a selection indicator.

Renders label at (ix, iy). If is_selected is true the text is drawn in MENU_NAV_COLOR_SELECTED with a dot indicator; otherwise it uses MENU_NAV_COLOR_NORMAL.

Parameters
ixHorizontal screen position in pixels.
iyVertical screen position in pixels.
labelNull-terminated option label to render.
is_selectedtrue if this option is currently highlighted.
