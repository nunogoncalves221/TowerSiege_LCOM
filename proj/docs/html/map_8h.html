Detailed Description

Tile-based game map definition and rendering.

The map is a fixed grid of MAP_COLS × MAP_ROWS tiles. Each tile is either grass (placeable), path (enemy route), or blank (tower slot). The map caches its rendered state and only redraws when marked dirty.
