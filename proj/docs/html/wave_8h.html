Detailed Description

Enemy wave spawning logic.

Manages the current wave number and the timed spawning of enemies into the active enemy array. The wave advances automatically once all enemies from the previous wave have been cleared.

Advances the wave timer and spawns enemies when appropriate.

Must be called once per game tick. When the spawn timer fires, a new enemy_t is appended to enemies and enemy_count is incremented. The function handles wave transitions internally.
