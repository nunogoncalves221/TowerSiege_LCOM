Detailed Description

Core game loop, input routing, and global game constants.

Owns the top-level game state: the map, hero, towers, enemies, and waves. The main application loop calls game_tick() and game_draw() every frame, and forwards hardware events through the handle functions below.

Returns whether the game session has ended.
