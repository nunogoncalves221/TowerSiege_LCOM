Detailed Description

Enemy entity definition and per-enemy lifecycle functions.

Declares the enemy_t structure that represents a single enemy on the map, along with functions to create, update, draw, and destroy one enemy at a time. Higher-level coordination of multiple enemies is handled by the enemy_manager module.
