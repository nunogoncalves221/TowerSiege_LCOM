Detailed Description

Bitmap font rendering and string-width measurement.

Provides functions to draw text strings and to measure their pixel width before drawing. All glyphs are rendered from a built-in bitmap font; characters are coloured by tinting each non-transparent pixel with the supplied AARRGGBB colour.
