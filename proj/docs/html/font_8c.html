Draws a string at the given screen position.

Each pixel of every glyph is tinted to color. Transparent glyph pixels are skipped.

Parameters
xLeft edge of the first character, in screen pixels.
yTop edge of the first character, in screen pixels.
sNull-terminated string to draw.
colorTint colour in AARRGGBB format.
Returns
Total pixel width rendered (same value as font_string_width()).

Draws a string with each glyph pixel scaled to a square block.

Every logical pixel of every glyph is rendered as a scale × scale block of screen pixels, producing an integer-scaled appearance.

Parameters
xLeft edge of the first character, in screen pixels.
yTop edge of the first character, in screen pixels.
sNull-terminated string to draw.
colorTint colour in AARRGGBB format.
scaleInteger scale factor (1 = normal size, 2 = double, …).
Returns
Total pixel width rendered at the given scale.
