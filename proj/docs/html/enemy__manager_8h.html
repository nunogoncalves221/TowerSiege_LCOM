Detailed Description

Batch update and draw for all active enemies.

Iterates over the active enemy array each tick, delegating per-enemy movement to enemy_update(), detecting base-reach events, and culling dead enemies from the array.

Updates all active enemies and handles collisions and deaths.

Must be called once per game tick. Moves each enemy, checks whether it has reached the player's base (removing a life), and removes enemies whose hp has dropped to zero.
