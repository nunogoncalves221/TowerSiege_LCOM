\doxysubsection{Detailed Description}
Tile-\/based game map definition and rendering. 

The map is a fixed grid of \doxylink{map_8h_a0c8fa5f924e3cb0ab18aa9ef5563ec23}{MAP\+\_\+\+COLS} × \doxylink{map_8h_abeb9c94c1e5b0cb6b5aea0884b1fb942}{MAP\+\_\+\+ROWS} tiles. Each tile is either grass (placeable), path (enemy route), or blank (tower slot). The map caches its rendered state and only redraws when marked dirty.
