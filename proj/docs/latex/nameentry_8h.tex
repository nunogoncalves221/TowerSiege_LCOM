\doxysubsection{Detailed Description}
Single-\/line name input widget for the high-\/score entry screen. 

Manages a fixed-\/length text buffer that the player edits with the keyboard. The caller drives it by forwarding raw scancodes and queries the result once the player confirms with Enter.
