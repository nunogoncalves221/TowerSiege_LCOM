\doxysubsection{Detailed Description}
Batch update and draw for all active enemies. 

Iterates over the active enemy array each tick, delegating per-\/enemy movement to \doxylink{enemy_8c_a6279af2a46427e7a3b804eb217643058}{enemy\+\_\+update()}, detecting base-\/reach events, and culling dead enemies from the array.
