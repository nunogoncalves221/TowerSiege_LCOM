\doxysubsection{Detailed Description}
Application state machine enumeration. 

Defines all possible high-\/level states that the application can be in. The main loop in {\ttfamily \doxylink{main_8c}{main.\+c}} reads the current state each iteration and dispatches input, update, and draw calls to the appropriate module.
