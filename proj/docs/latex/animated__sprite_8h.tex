\doxysubsection{Detailed Description}
Multi-\/frame animated sprite with tick-\/based playback control. 

An \doxylink{structAnimSprite}{Anim\+Sprite} wraps a base \doxylink{structsprite__t}{sprite\+\_\+t} and a set of per-\/frame pixel maps. The animation advances one frame every {\ttfamily aspeed} game ticks, and two playback modes are supported\+: looping (e.\+g. walking/idle) and one-\/shot (e.\+g. attack/death).
