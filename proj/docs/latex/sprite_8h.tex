\doxysubsection{Detailed Description}
Static sprite representation and drawing utilities. 

A sprite holds only the visual representation of a game object\+: its dimensions and the raw pixel colour map. As recommended in the lectures, game-\/logic data (position, velocity, etc.) is kept separate from the visual data.
