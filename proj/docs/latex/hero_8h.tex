\doxysubsection{Detailed Description}
Player-\/controlled hero character. 

Manages the hero\textquotesingle{}s position, health, animations, and melee attack state machine. The game loop drives the hero by forwarding keyboard state each tick and calling \doxylink{hero_8h_a10e1989996dc60bfb17e92268dd2ad01}{hero\+\_\+tick()} to resolve movement and combat.
