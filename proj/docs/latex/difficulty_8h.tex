\doxysubsection{Detailed Description}
Difficulty selection screen and difficulty type definition. 

Defines the \doxylink{difficulty_8h_a3a922b9bea86b62e5a3292061e50ab08}{difficulty\+\_\+t} enumeration used throughout the game to scale enemy stats and spawn rates, and provides the keyboard-\/driven selection screen shown before a new game begins.
