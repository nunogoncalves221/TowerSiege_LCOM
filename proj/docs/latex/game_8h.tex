\doxysubsection{Detailed Description}
Core game loop, input routing, and global game constants. 

Owns the top-\/level game state\+: the map, hero, towers, enemies, and waves. The main application loop calls \doxylink{game_8h_af8a50be77ba977aadb8ea6f85f91ecdb}{game\+\_\+tick()} and \doxylink{game_8h_af6beeef4bd774ee4c8ed789815e68833}{game\+\_\+draw()} every frame, and forwards hardware events through the handle functions below.
